## 🌟 Features
- **Executive Hero Profile**: Full designation, bio, and portrait showcase.

- **Direct Communication Channels**: WhatsApp direct messaging and direct phone calling.
- **Interactive Foundation Hub**: Core impact programs, verified statistics counter, and foundation mission/vision.
- **Residence & Postal Location**: Interactive directions and clipboard copy for Plot No 7, Vasanth Nagar, Mutharasanallur, Trichy - 620101.
